# Hospital Database Project

## 📌 Overview
This project is a relational database system designed to manage hospital operations using SQL.  
It represents a real-world hospital environment by organizing data related to patients, medical staff, departments, rooms, appointments, admissions, and prescriptions.

The project was developed for educational purposes to apply database design concepts, normalization, and advanced SQL queries.

---

## 🏥 Database Entities
The database includes the following entities:

- Patient  
- Department  
- Doctor  
- Nurse  
- Manager  
- Employee  
- Room  
- Appointment  
- Admission  
- Prescription  

Each entity is designed with appropriate primary keys, foreign keys, and constraints to maintain data integrity and consistency.

## 📊 SQL Features
The project includes:
- Creating tables using CREATE TABLE
- Inserting data using INSERT
- Executing queries using:
  - Joins
  - Subqueries
  - Views
  - Aggregate functions
  - Set operations (UNION, INTERSECT, MINUS)
  - UPDATE and DELETE statements
